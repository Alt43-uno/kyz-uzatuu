# Кыз узатуу

Сайт работает целиком на GitHub Pages: `index.html` и папка `assets`. Форма отправляет имя и ответ гостя прямо в Telegram, в группу «Узатуу». Отдельный сервер, Vercel и установка пакетов не нужны.

Для публикации обновите `index.html` в репозитории — настройки GitHub Pages, DNS и CNAME менять не требуется.

В `index.html` настройки находятся в `telegramTokenParts` и `telegramChatId`. Токен тестового бота закодирован в Base64 и разделён на части. Это маскировка, а не шифрование: посетитель может восстановить токен и увидеть его в сетевом запросе. Этот вариант выбран с учётом допустимости раскрытия тестового токена.

При отправке кнопка блокируется. Успех появляется только после подтверждения Telegram; при ошибке или ожидании дольше 12 секунд данные остаются в форме для повтора. При потере ответа повторная отправка может создать дубликат.

Локальный `.env.local` оставлен как исключённая из Git копия настроек; сайт его не читает.
